Como testar a extensão:
  1. Carregue a pasta SEI-Fluxo em chrome://extensions (modo desenvolvedor).
  2. Abra este arquivo via servidor local ou adicione o caminho aos host permissions se necessário. Para demo rápida, sirva a pasta e acesse via http://localhost.
  3. A barra SEI Fluxo deve aparecer à direita com o fluxograma do tipo selecionado.
  4. Altere o tipo no select para ver a troca de fluxo em tempo real (reanálise automática).
