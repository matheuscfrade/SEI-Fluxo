Fontes de fluxos

Adicione arquivos JSON (um departamento) e/ou uma pasta do Google Drive com vários JSON (instituição inteira). Cada .json da pasta vira um catálogo (nome = nome do arquivo). Se o mesmo tipo existir em mais de um JSON, no SEI o usuário escolhe qual exibir.

Pasta e arquivos devem estar como Qualquer pessoa com o link — Leitor. Link de pasta: https://drive.google.com/drive/folders/…

Opção avançada: chave da API Google (listagem de pastas)

Em algumas pastas a listagem pública falha. Uma chave da Google Drive API (somente leitura, restrita) melhora a detecção dos .json. Fica só neste navegador. Deixe em branco se não precisar.

Conflitos de tipo de processo

Mais de um arquivo cadastrou o mesmo nome exato de tipo de processo. No SEI a barra mostra um aviso e permite escolher e alternar entre os fluxos disponíveis.

Fluxos disponíveis

Como publicar (por departamento)

  1. Monte os fluxos do departamento abaixo e clique em Baixar JSON.
  2. Envie o arquivo ao Google Drive do departamento.
  3. Compartilhe: Qualquer pessoa com o link → Leitor.
  4. Na aba Catálogo, adicione o link do arquivo ou coloque vários JSON numa pasta do Drive e use + Pasta do Drive.
  5. Clique em Carregar todos os fluxos. Se o mesmo tipo existir em mais de um JSON, o usuário escolhe qual ver no SEI.

Editor

Gera o JSON de um departamento. O SEI usa apenas o que foi carregado pelos links do Catálogo.

Selecione ou crie um fluxo

Defina o tipo de processo e as etapas. Depois baixe o JSON e publique no Drive do departamento.

Editar fluxo

O nome deve ser idêntico ao campo Tipo no SEI (não usa nomes alternativos).
