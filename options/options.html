Fontes de fluxos

No SEI o fluxo aparece como Instituição | Departamento | Nome do Fluxo (ex.: IFMG | RE-DDI | Geral: Estruturas e Regimentos IFMG).

  • Arquivo JSON — informe instituição + departamento + link do arquivo.
  • Pasta do Drive — informe a instituição + link da pasta; cada .json vira um departamento (nome do arquivo).

Pasta e arquivos: Qualquer pessoa com o link — Leitor. Nome do fluxo = flowName (ou processType, se vazio). Match no SEI = processType (nome exato do Tipo).

Conflitos de tipo de processo

Mais de um arquivo cadastrou o mesmo nome exato de tipo de processo. No SEI a barra mostra um aviso e permite escolher e alternar entre os fluxos disponíveis.

Fluxos disponíveis

Como publicar

  1. Monte os fluxos e clique em Baixar JSON. processType = Tipo no SEI; flowName = nome específico do fluxo (opcional, útil se o tipo tiver vários).
  2. Envie ao Drive: arquivo avulso (ex.: um departamento) ou pasta com vários JSON (ex.: RE-DDI.json, RH.json).
  3. Compartilhe: Qualquer pessoa com o link → Leitor.
  4. No Catálogo: arquivo → instituição + departamento + link; pasta → instituição + link (departamento = nome do arquivo).
  5. Clique em Carregar todos os fluxos. No SEI aparece Instituição | Departamento | Nome do Fluxo.

Editor

Gera o JSON de um departamento. O SEI usa apenas o que foi carregado pelos links do Catálogo.

Selecione ou crie um fluxo

Defina o tipo de processo e as etapas. Depois baixe o JSON e publique no Drive do departamento.

Editar fluxo

Chave de identificação: deve ser idêntico ao campo Tipo no SEI. O mesmo tipo pode ter vários fluxos abaixo.

Nome específico deste fluxo de trabalho. Use quando o mesmo tipo SEI tiver mais de um fluxo (ex.: “Plano de Oferta de Cursos e Vagas”). Se vazio, a UI usa o tipo do processo.
